# دفتر النقوط (ليا / عليا)

تطبيق ويب (PWA) بالعربي لتسجيل الفلوس اللي ليك واللي عليك. الدخول بحساب جوجل أو إيميل وباسورد، والداتا بتتحفظ في Firebase وتتزامن بين كل أجهزتك، ويفتح من غير نت.

## المميزات

- أشخاص ومعاملات (ليا / عليا)، ورصيد كل شخص = مجموع (ليا) − مجموع (عليا).
- بحث بالاسم، وفلترة: دوس على مربع **ليا** أو **عليا** فتشوف الأسماء اللي تخصه، الأكبر مبلغاً الأول.
- تسجيل أي مبلغ ليا أو عليا في أي وقت، من غير قيود.
- **مواعيد السداد**: حدّد موعد لكل شخص، وصندوق "مواعيد السداد" في الرئيسية بيظهر المتأخر واللي خلال 7 أيام. السداد الكامل بيمسح الموعد.
- تعديل وحذف أي معاملة أو شخص (الحذف بتأكيد).
- **تصدير Excel** (ملخص + الأشخاص + المعاملات) بزرار "تصدير".
- فاتح وداكن، وبيتثبت على شاشة الموبايل كتطبيق.
- مفيش إشعارات Push. التذكير جوه التطبيق بس (صندوق المواعيد).

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` / `style.css` / `app.js` | الشاشات والتصميم والمنطق |
| `auth.js` | الدخول (Firebase Auth) |
| `db.js` | الحفظ والمزامنة (Firestore) |
| `firebase-config.js` | إعدادات مشروعك (`daftar372`) |
| `firestore.rules` | قواعد الأمان (كل مستخدم يشوف دفتره هو بس) |
| `sw.js` + `manifest.json` + `icon-*.png` | التثبيت والعمل من غير نت |

## الداتا

- `users/{uid}/people/{id}`: الاسم، التليفون، موعد السداد.
- `users/{uid}/transactions/{id}`: الشخص، النوع (ليا / عليا)، الصنف (دين / سداد)، المبلغ، التاريخ، ملاحظة.

## إعداد Firebase (مرة واحدة، من الموبايل أو الكمبيوتر)

1. **Authentication ← Sign-in method**: فعّل **Google** و**Email/Password**.
2. **Firestore Database ← Create database**: اختار **production mode** وأقرب منطقة (مثلاً `eur3`). المنطقة مش بتتغير بعدين.
3. من تبويب **Rules** في Firestore: امسح الموجود والصق محتوى `firestore.rules`، واضغط **Publish**.
4. (اختياري) **Authentication ← Templates ← Password reset**: غيّر اللغة لعربي.

## النشر على GitHub Pages (من الموبايل)

1. في github.com اعمل **New repository** باسم `naqout`، واجعله **Public** (Pages المجانية بتحتاج كده).
2. فك ضغط `naqout-app.zip` (من تطبيق الملفات في الموبايل: دوس على الملف).
3. في الريبو: **Add file ← Upload files**، واختار كل الملفات اللي طلعت من الفك (مش الـ zip نفسه)، واضغط **Commit changes**.
4. **Settings ← Pages**: Source = **Deploy from a branch**، Branch = `main` و `/ (root)`، واضغط **Save**.
5. بعد دقيقة هيظهر الرابط: `https://USERNAME.github.io/naqout/`.
6. في Firebase: **Authentication ← Settings ← Authorized domains ← Add domain**، وضيف `USERNAME.github.io` (الدومين بس، من غير `https://` ولا `/naqout`).

لو استعملت كمبيوتر: `npm i -g firebase-tools`، ثم `firebase login` و`firebase init hosting` (Public directory = `.` ومن غير single-page)، ثم `firebase deploy`. الرابط هيكون `https://daftar372.web.app` وهو مضاف في Authorized domains تلقائياً.

## تثبيته على شاشة الموبايل

- **آيفون (Safari)**: زرار المشاركة ← **Add to Home Screen**.
- **أندرويد (Chrome)**: القايمة ← **Install app**.

ملحوظة آيفون: الدخول بجوجل من أيقونة الشاشة الرئيسية ممكن ما يشتغلش في بعض إصدارات iOS (قيد من أبل). لو حصل، ادخل بالإيميل والباسورد، أو افتح التطبيق من Safari.

## اختبار (على الرابط المنشور)

1. افتح الرابط ← شاشة الدخول. ادخل بجوجل ← الرئيسية وإيميلك ظاهر و"✓ متزامن".
2. دوس **+**، أضف "أحمد" وتليفونه. افتحه، دوس **+ ليا** وسجّل 500، وبعدها **+ عليا** وسجّل 200 ← "ليا عنده 300".
3. سجّل **+ عليا** 400 تانية: يتحفظ ويتحول الرصيد لـ "عليا 100".
4. دوس **تعديل** وحط موعد سداد امبارح (بعد ما تسجّل دين جديد) ← يظهر في الرئيسية "متأخر" في صندوق مواعيد السداد.
5. دوس مربع **ليا** ثم **عليا** ثم **الكل**، وجرّب البحث بالاسم.
6. دوس **تصدير** ← يتنزّل ملف Excel فيه ثلاث شيتات.
7. افتح التطبيق من موبايل تاني بنفس الحساب ← نفس الداتا. اقفل النت واعمل تعديل ← يتحفظ ويتزامن لما النت يرجع.
8. اخرج وادخل بحساب تاني ← دفتر فاضي (محدش يشوف داتا حد).
